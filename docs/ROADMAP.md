# Roadmap

Phase 1 focuses on Japanese → English native PDFs, explicit QA and editable LaTeX.

Next: stronger paragraph/column segmentation, mixed-style English runs, interactive
layout-box adjustment, partial-page rebuild optimization, reliable rotated scan cleanup,
local-window SSIM and better overlap/residual masks, richer fixture coverage, cross-process
job coordination, sandboxed PDF/TeX workers, and automated browser regression tests.

Later: language/provider adapters; evaluated 24/32 GB memory profiles; optional larger
models after human benchmarks; richer scans with conservative restoration; a Tauri or
SwiftUI shell and signed/notarized app packaging; accessible document reconstruction.

Deferred: universal typography restoration, handwriting, general layout editing, exact
hyperlink/annotation/tag trees, editable formula reconstruction, all-language translation,
cloud inference, model training, audio/TTS and collaboration. No implicit cloud fallback.
